# 서울시 공공미술품 현황 지도 · 공동연구용 데이터 (2026-10-14 판)

웹지도: https://hcraan.github.io/seoul-public-art-map/

> 이 저장소에는 웹지도와 분석용 데이터(`data/`)가 있습니다. **엑셀 원자료(`원자료_정리본_규격재코딩.xlsx`)는 작가·소유주 연락처가 들어 있어 공개 저장소에 올리지 않았습니다.** 엑셀이 필요한 연구진은 별도로 공유받은 압축파일을 쓰세요. 아래 설명에서 엑셀을 언급하는 부분은 그 파일 기준입니다.

> **AI에게 이 파일을 줄 때**: 이 README를 먼저 읽게 하세요. 분석은 `data/artworks.csv` 하나로 시작하면 됩니다.


## 3. 규격 재조사 (2026-10-13) — 반드시 읽어 주세요

원자료의 규격 칸 이름은 "규격(cm)"이고 대부분 숫자 3개가 cm로 적혀 있습니다. 그런데 일부는 mm·10cm·m로 잘못 입력되거나 다른 작품 숫자가 복사되어 있었습니다(예: SPRING의 원문 "560 600 21500"은 5.6×6.0×21.5m인데 cm로 읽으면 215m). 그래서 362건 전체를 다시 정리했습니다.

| `규격_확인` | 뜻 | 전체 | 지도 표시 |
|---|---|---|---|
| **확정** | 원문을 cm로 읽어 자연스럽거나, 원문 글·다른 칸·작품 설명·연구진 확인으로 뒷받침되는 값 | 256 | 132 |
| **추정** | 값은 맞을 가능성이 높지만 확인 안 됨 (원문에 숫자 1개만 기재, cm로 읽어 15m 이상인데 근거 없음 등) | 45 | 37 |
| **재조사 필요** | 원문이 틀렸다고 보고 고친 값이거나 원문 자체가 의심스러운 값 (단위 오류, 원문 복사·판독 의심, 동상 높이가 두 가지 등) | 31 | 23 |
| **미상** | 규격 정보 없음 (빈칸, "0 0 0", 판독 불가) | 30 | 27 |

- **`규격_재코딩_m`** = 가장 긴 변(m). **`규격1_m`·`규격2_m`·`규격3_m`** = 원문 순서대로의 세 값(대체로 가로·세로·높이). **`규격_근거`** = 판단 이유.
- 동상처럼 "좌대 높이 + 동상 높이"가 따로 적힌 경우 둘을 더한 높이를 씁니다.
- **규격으로 분석할 때는 `규격_확인`이 "확정"인 작품만 쓰거나, "재조사 필요"를 빼고 결과가 달라지는지 확인하세요.**
- 엑셀 '규격 확인 목록' 시트에 재조사 필요·추정·미상 106건이 정리되어 있고, 노란 칸에 확인값을 적을 수 있습니다.
- 엑셀의 예전 정리 칸 `규격_가장긴변_cm`(BB)·`규격구간`(BC)은 재조사 전 값입니다. CSV의 `규격구간`은 새 값으로 다시 계산했고, 웹지도도 새 값을 씁니다.

## 4. 자치구·위치 관련 주의사항

1. **`자치구`·`행정동`은 좌표로 계산한 값**입니다. 좌표를 `seoul_dongs.geojson` 경계와 겹쳐 계산했습니다. 원자료에도 '지역' 칸(엑셀 AF열)에 자치구가 적혀 있으며, CSV에 `지역_원자료`로 함께 넣었습니다. 둘은 아래 6건만 다릅니다.
2. **서울 밖 작품 37건**: 서울대공원(경기 과천시) 11건은 `서울 밖(경기 과천시)`, 횡성 수장고 26건은 `서울 밖(강원 횡성군)`입니다. 둘 다 `행정동`은 빈칸입니다.
3. **주소 기준 보정 6건**: 주소의 구와 좌표로 계산한 구가 달라, 주소의 구를 따랐습니다(`자치구_판정` = "주소 기준 보정 (좌표상 …)"). 모두 구 경계에서 50m 안쪽입니다.
   - 청계광장 3건(SA0006, SI0095, SI0096): 좌표상 중구 → 종로구
   - 남산 안중근의사기념관 2건(SM0018, SS0017): 좌표상 용산구 → 중구
   - 양재천 영동2교 1건(DA0081): 좌표상 강남구 → 서초구
   - ⚠ 원자료 '지역' 칸은 청계광장 3건을 **중구**, 남산 2건을 **용산구**로 적고 있어 좌표 쪽과 같습니다(DA0081만 주소와 같은 서초구). 즉 원자료 안에서도 주소와 지역이 엇갈립니다. 현재는 주소 기준을 임시로 따르고 있으며, 확인 후 바뀔 수 있습니다.
   - 그 밖에 SA0062 동심속으로(여의도한강공원)는 원자료 '지역'이 동작구, 좌표 계산은 영등포구입니다. 여의도한강공원은 영등포구이므로 좌표 쪽(영등포구)을 따랐습니다.
4. **같은 좌표에 여러 작품**: 서울추모공원 11점처럼 층·장소가 다른데 좌표가 하나인 경우가 있습니다(`같은위치_작품수`). 지점 수와 작품 수를 구분하세요.

## 5. 그 밖의 주의사항

- **가액 단위는 백만 원**입니다(`가액_백만원` 117 = 1억 1,700만 원). 빈칸 = 미상, 0 = 기증·무상. `가액_비고`가 "사업 전체 금액만 기재"인 작품은 여러 작품 합계라 빈칸입니다. 기증 작품 가액 처리가 제각각입니다(SA0006 KT 기부 35억 원 "금액 확인 필요" 등).
- **생애주기 경과 기준연도는 2026년**: 만료연도 2025년까지(2025 포함) → 기간 지남, 2026~27 → 곧 만료, ≥ 2028 → 기간 남음. `영구(추정)`은 기념비·동상 중 원자료 빈칸을 영구로 간주한 추정입니다. 생애주기경과 "정보 없음"에는 "미정·기타"도 포함됩니다.
- **"정보 없음"이 많은 칸**: 공공미술포털 등록 여부, 생애주기 등은 미등록·만료 건수를 최소치로 보세요.
- **원자료 오타 의심**: DA0081 작품명 "잆어요", 주소 "서울시 과천시"(SS0009·SS0010) 등은 원문 그대로 두었습니다.
- 원자료에서 빈칸 대신 "." 이나 "-"를 적은 경우가 있습니다(소유주·설명·재료 등). CSV는 원문 그대로 두었으니 분석 때 빈칸으로 처리하세요.
- 동상 등 일부 작품은 높이 하나만 적혀 있어 `규격_재코딩_m`(가장 긴 변)이 사실상 높이입니다.
- `작품유형` "기타"는 기념비·동상·도시갤러리·서울은미술관에 속하지 않는 나머지입니다.

## 7. 각자 AI로 분석하는 방법

1. 이 저장소의 `README.md`와 `data/artworks.csv`를 내려받아 AI 대화창에 올립니다(공유받은 zip 파일을 그대로 올려도 됩니다).
2. 첫 요청 예시:
   > 첨부한 서울시 공공미술 패키지의 README.md를 먼저 읽고, 주의사항을 지켜서 data/artworks.csv로 분석해줘.
   > 질문: 지도에 표시되는 작품 중 자치구별로 '생애주기 기간 지남' 작품이 몇 점인지, 그중 공공미술포털 미등록은 몇 점인지 표로 정리해줘.
3. 분석 예시: 설치 시기별·유형별 작품 수 변화 / 행정동 단위 분포 지도 / 유형별 평균 가액 / 생애주기 만료 임박 작품과 관리부서 / 규격 확정 작품만으로 크기 분포 / 다른 공간자료(인구·공원 등)와 좌표 결합

## 8. 웹지도(index.html)

- 브라우저에서 열면 됩니다. 지도 프로그램(MapLibre)과 배경지도(OpenFreeMap·OpenStreetMap·Esri)를 인터넷에서 받아오므로 인터넷 연결이 필요합니다.
- **배경지도 3가지**: '99.지도 레이어' 제목 오른쪽 버튼으로 **주제도**(기본, OpenFreeMap 색칠) / **일반 지도**(OpenStreetMap) / **위성사진**(Esri World Imagery)을 고릅니다. 일반 지도·위성사진에서는 '도로망·한강', '건물·공원'이 잠기고, 대신 '행정동 면 (배경지도 흐리게)'를 켜고 끌 수 있습니다. 어느 배경지도든 서울·과천 바깥은 흰색으로 가립니다.
- **과천시 표시**: 서울대공원 작품(경기 과천시 11건)이 있어 배경지도를 과천시까지 넓혔습니다. 과천은 연한 회색을 덧씌워 서울과 구분하고, 바깥 경계는 점선, '과천시' 이름은 늘 보입니다(켜고 끄는 항목 없음).
- '작품 규격' 필터와 원 크기는 2026-10-13 재조사값입니다. 작품 정보창의 규격 칸에 세 값(예: 5.6 × 6.0 × 21.5m), 가장 긴 변, 판단 근거가 나오고, 추정이면 노란색, 재조사 필요면 빨간색 표시가 붙습니다.
- 웹지도는 `data.js`를 읽습니다. `data/` 파일을 고쳐도 웹지도는 바뀌지 않습니다.
